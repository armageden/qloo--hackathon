# TourAgent Module

Located at `src/tour-agent.js`.

The `TourAgent` class orchestrates the end-to-end transformation of an artist entity and tour city into a 24-hour cultural takeover itinerary and executive sponsorship proposal.

## Class Definition

```js
import { tourAgent, TourAgent } from "./src/tour-agent.js";
```

### Constructor
```js
new TourAgent(client = qlooClient)
```
Accepts an instance of `QlooClient` (defaults to the singleton instance).

## Key Methods

### `generateTourPackage(artistInput, cityKey)`
- **Parameters:**
  - `artistInput` *(string)*: Name or slug of the touring act (e.g. `"chappell-roan"`, `"kendrick-lamar"`).
  - `cityKey` *(string)*: Target city key (e.g. `"chicago"`, `"new-york"`, `"los-angeles"`).
- **Behavior & Intelligence Pipeline:**
  - **Entity Normalization & Resolution**: Recognizes live entities returned with types `urn:entity:artist`, `urn:entity:person`, or `urn:entity:music`.
  - **Dynamic Custom Artist Synthesis**: For uncataloged performers, invokes `synthesizeCustomArtistData` to generate a dynamic genre-aligned cultural taste profile (Rock/Metal, Hip-Hop/Rap, Electronic/Dance, Country/Americana, Comedy/Stand-Up, Indie/Pop) without falling back to fixed presets.
  - **Taste-Aligned Neighborhood & Venue Routing**: Routes the 24-hour takeover to culturally and taste-aligned city districts and venues based on artist genre, vibe, and audience demographic (e.g., routing Cedric the Entertainer to West Loop / Fulton Market culinary institutions like Virtue Restaurant, Kumiko, and Lazy Bird Subterranean Soul Lounge).
- **Returns:** Promise resolving to an object containing:
  - `metadata`: Execution timing, venue name, and city. `metadata.provenance` records entity-resolution and per-domain recommendation sources, distinguishes local artist/city data, and exposes `liveDataUsed`; `qlooMode` reflects live/mixed data actually incorporated rather than key configuration.
  - `artistProfile`: Genres, vibe description, and demographic profile.
  - `culturalAffinities`: Domain-specific affinity arrays (dining, nightlife, fashion, brands, film/TV).
  - `itinerary`: Array of 6 chronological stops from morning fuel to late-night eats.
  - `brandSponsorshipMatrix`: 4 high-affinity brand sponsor proposals with activation concepts and pitch notes.
  - `executiveSummary`: High-level strategic briefing text.

### `answerAgentQuery(query, activePackage)`
- **Parameters:**
  - `query` *(string)*: Natural language question from the user or promoter.
  - `activePackage` *(object|null)*: Current tour package context.
- **Behavior:**
  - Performs intelligent semantic routing for negative sponsor risks, brand alignment failures, live LLM vs. Qloo Taste Graph comparisons, audience demographics, and venue curation logic.
  - Directly cites live Qloo affinity metrics, quantified percentages, and cultural affinity vectors.
- **Returns:** Promise resolving to:
  ```json
  {
    "answer": "Explanation grounded in Qloo affinity data...",
    "dataPoints": ["Metric 1", "Metric 2"]
  }
  ```

### `compareAudiences(artistAInput, artistBInput)`
- **Parameters:**
  - `artistAInput` *(string)*: First touring performer name or slug.
  - `artistBInput` *(string)*: Second touring performer name or slug.
- **Returns:** Promise resolving to:
  ```json
  {
    "artistA": { "name": "Chappell Roan", "genres": [...] },
    "artistB": { "name": "Charli XCX", "genres": [...] },
    "overlapScore": 69,
    "feasibilityVerdict": "High Co-Headline Feasibility",
    "strategicRecommendation": "Prime candidates for co-billing...",
    "sharedAffinities": { "dining": [...], "brands": [...] },
    "divergence": { "artistAExclusive": "...", "artistBExclusive": "..." },
    "provenance": "Qloo Multi-Domain Audience Affinity Comparison"
  }
  ```

### `calculatePromoterEconomics(packageData, capacityTier)`
- **Parameters:**
  - `packageData` *(object)*: Full tour package generated by `generateTourPackage`.
  - `capacityTier` *(string)*: Venue capacity tier (`club`, `theater`, `arena`, `stadium`).
- **Returns:** Financial modeling object with ticket gross, multi-tier sponsorship rights valuations, per-head concourse spend lift, VIP afterparty unlock, and executive promoter pitch.

### `planTourLeg(artistSlug, cityKeys)`
- **Parameters:**
  - `artistSlug` *(string)*: Performer slug or name.
  - `cityKeys` *(string[])*: Array of metropolitan tour market keys (e.g. `["chicago", "new-york", "los-angeles"]`).
- **Returns:** Strategic tour leg object containing aggregate ticket capacity, cumulative ancillary revenue unlock, per-stop stopover cards, and multi-city universal brand partner synergies.

### `hasLLMConfigured()` & `setLLMKey(key, model)`
- Detects and manages runtime configuration for live Gemini 3.8 Flash agentic reasoning with automatic offline fallback.
